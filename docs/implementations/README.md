# Implementation status

Hardware and firmware facts live in the rest of this wiki. This directory records **how a particular operating system implemented them**.

| Page | Role |
|------|------|
| [Zlyme](zlyme.md) | **Active** Miyoo Flip OS maintained by this project |
| [ROCKNIX fork](rocknix.md) | **Archived** historical implementation and evidence |
| [Stock](stock.md) | Vendor firmware (Miyoo), with versions called out |

Official [ROCKNIX/distribution](https://github.com/ROCKNIX/distribution) is a separate upstream project. It is an external reference for generic RK3566 work. It does not define this project’s Miyoo Flip state.
